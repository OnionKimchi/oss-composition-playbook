# 문서 작성 참고 자료

아래 자료는 문서 구성과 지침 전달 방식의 참고 자료입니다. 본 저장소의 전체 아키텍처 제안과 일치하는 선행 제안으로 제시하지 않습니다. 본 제안의 최초성도 주장하지 않습니다.

| 자료 | 참고할 작성 방식 |
| --- | --- |
| [Agent OS](https://github.com/buildermethods/agent-os) | AI에게 개발 기준을 문서로 전달하고 필요한 기준을 정리하는 방식 |
| [GitHub Spec Kit](https://github.com/github/spec-kit) | 원칙·요구사항·계획·작업을 구분하는 문서 흐름 |
| [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/) | 문제와 해결 방향을 짝지어 설명하는 패턴 문서 방식 |
| [Azure Anti-Corruption Layer](https://learn.microsoft.com/en-us/azure/architecture/patterns/anti-corruption-layer) | 적용 조건과 고려 사항을 명시하는 설명 방식 |
| [arc42](https://arc42.org/overview/) | 목표·제약·구성·결정·위험을 구분하는 아키텍처 문서 구성 |

확인일: 2026-10-17. 외부 문서 본문이나 템플릿을 복제하지 않았습니다. 해당 프로젝트와의 제휴나 검토·승인을 의미하지 않습니다.
